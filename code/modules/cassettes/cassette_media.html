code/modules/cassettes/cassette_media.dm

/proc/cassette_uses_floxyCassettes use Floxy when it's fully set up
/proc/fetch_cassette_metadataMetadata for a song, list("title", "url", "duration", "artist", "album")
/proc/queue_cassette_mediaGets a song ready to be played ahead of time
/proc/get_cassette_mediaWaits for a song and returns list("status", "url", "endpoints", "metadata"), null if it couldn't be found
/proc/ytdl_lookupLooks the URL up with yt-dlp and returns what Floxy would
/proc/ytdl_user_cooldownReturns TRUE if this player has to wait, otherwise starts their cooldown
/proc/ytdl_url_allowedOnly sites from REQUEST_INTERNET_ALLOWED are looked up, players can put any link on a tape and yt-dlp would fetch all of them
/proc/ytdl_url_shell_safeTRUE if the url is made only of characters that can sit inside quotes in a shell command. Unsafe urls are refused instead of rewritten, shell_url_scrub() percent-encodes characters like "-" and breaks the link
/proc/ytdl_runReturns list(errorcode, stdout, stderr). shell() waits for the command, which freezes the whole server while yt-dlp works, so on unix it is started in the background and the result is polled
/proc/ytdl_parseTurns yt-dlp's json into the list Floxy gives out, null if the song can't be played
/proc/ytdl_textText from the internet that is shown to players
